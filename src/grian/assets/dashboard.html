Forecast vs actual ◉ focused model (every execution pattern — drag the slider to pan)

Actual price against the model's forecast under each executor. The recorded forecast is the model's point forecast, which is the same no matter how the fan is dispatched — so dispatch-only variants (point OL vs spike-gated MPC, or robust / EV / CVaR) draw the same line, shown with different dash styles where they overlap. The only thing that changes the forecast itself is the re-forecast cadence: open-loop is the raw day-ahead forecast committed once per day; MPC 30-min re-forecasts intraday, so you see its ever-fresh near-term view.

Day-ahead forecast trajectory ◉ focused model (one committed forecast vs what happened)

The full 48-step forecast a config commits at a single origin (midnight), plotted against the prices that actually followed — how good was the day-ahead plan? Shown only for configs that commit a day-ahead trajectory (open-loop / daily-reforecast); an every-interval MPC has no single day-ahead plan, so it's hidden.
